勘探者协会是灰都官方的委托发布机构，任何不甘于平凡生活的萨维恩人都能选择成为一名勘探员。勘探员区别于佣兵，它们的主要目标是勘探目标区域，回收特定物品与数据，发现新矿物或动植物。深入特定的荒野与地底去寻找那些埋藏在灰星的宝藏，它们往往能够一夜暴富，彻底摆脱天天蹲在工厂打螺丝的日子，但是相对的它们将会面临最残酷的风险与威胁。

勘探员没有任何注册门槛，但初入者只能选择最基础的一级委托。这些任务由协会评估，有着更安全也更低廉的报价；只有完成任务、积累声望，才能成为更资深的勘探员，获取更高级别的任务。

## 等级体系

| 入门 | 无牌（1声望） |
| 新手 | 铜牌（5声望） |
| 熟练 | 银牌（20声望） |
| 老练 | 金牌（100声望） |
| 勇士 | 骨牌（每增加100声望骨牌+1） |

最简单的任务给予100灰币与1声望，越危险其报酬与奖励越高。声望代表着他人与协会的认可，同时也是实力的象征。无论是公司还是企业，对顶级的勘探员也会客气几分。声望便是协会的信用点，用于解锁购买管制物资的权限。

## 任务与报酬

任务并非固定难度、一成不变。协会只能根据有限的情报与经验来评判任务的简单与否，最基础的入门任务也可以成为连金牌都九死一生的威胁。

企业、公司、协会甚至是个人都能在协会内发布任务，其支付的报酬各异，也不局限于单纯以灰币为报酬。同时协会也是最庞大的战利品交易市场，任务过程中得到的情报、物品，任何任务要求外的有价值物品都属于你的额外报酬，这也是许多勘探者暴富的来源。
