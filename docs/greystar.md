欢迎你，无论你以什么身份来到这个远离地球的地方，你肯定消耗了不少财力或者运气，外来者，Sawian，亦或是抱着开拓星空的野望，总之欢迎来到灰星。

灰星是一颗远离太阳系的星球，得益于跨空间的传送技术，距离和长途冷冻休眠的解冻症不再是问题，大量的物资和人力被投送到了这里，包括公司的员工与实验体们，当然现在我们现在不这样称呼他们了。

这个故事的起源已经被封存，只有公司和企业的核心高层知晓它们，对于其他人而言它们更像是诅咒，而我恰巧就是其中之一，那是一个遥远的故事。

@link: 过去 => greystar_past

总而言之，灰星现在由两大势力共同管理。

公司是最先来到这里的开拓者，它们来到了人力和技术，并投放了大量的物资，但是由于传送技术出现了一些偏差大量危险的战争机器与技术流落在这片大地之上带来了致命的威胁与难以想象的机遇。可以瞬间夺走你性命的地雷与还在运作的哨戒机枪在这里并不少见，回收它们很危险，但是也很有价值，无论是公司还是企业都会支付你一笔酬劳。

Sawian，它们原本是当地的原生物种，由于基因工程的介入它们脱颖而出并获得了智慧，公司和它们签订了一系列的，条例。它们现在有了工作，甚至有的加入了公司，多种多样，令人印象深刻，你会喜欢它们的，但是公司似乎对此态度模糊。

你想更了解一下公司？当然，我这里也有一些关于它们的故事。

@link: 公司 => greystar_company

企业，他们是后来的参与者，公司似乎意识到了自己在基建和星球改造上的不足，企业很好的弥补了这一点。灰都便是企业的手笔，每一块水泥砖上都能找到它们的标志，包括你能买到的营养膏，虽然它们寡淡无味，但是在一个充满危险武器和生物的外星球上能够有一个遮风挡雨的地方绝对能算是一种福泽。

企业对Sawian们的态度还算友好，它们的员工也很积极的参与到了灰都的建设之中，包括公共设施，甚至于只要你有足够的钱，你可以在这里过上在地球的日子。

但是所有人都有秘密，包括它们，你想知道吗？

@link: 企业 => greystar_enterprise

当然，也不是所有的Sawian都乐意生活在灰都，为公司或企业做事，也有不少Sawian远离了这里依靠散落在灰星上的设施过活，它们对公司甚至企业的态度有怀疑，有敌视，甚至直接袭击了当地设施。

它们自称拾荒者，远离灰都的生活，向往更自由的天地，这是有代价的，灰都之外的地方可不太平，但是总有人能在那里活下去，相传它们获得了一些人类的帮助。它们有着各自的理由，但是都不愿意成为那座庞大城市运转的燃料，但没有人能真正摆脱灰都。
